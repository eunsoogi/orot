# 일일 보고서 해석 경계

2026-11-15 공개 원문을 확인했다. 사용자 기록이나 화면은 이 문서와 테스트에 포함하지 않는다.

## 현재 지원하는 해석

`dailyReportGuidance`는 모델이 작성한 진단 대신, 검증된 원본 기록에 연결된 제한적 교육 안내를 생성한다. 혈압은 mmHg의 개별 측정을 사용하며 커프 측정의 수 초 구간도 포함한다. 다른 기기/시각의 수축기·이완기 값을 한 쌍으로 만들지 않는다. 수치가 정상 범위처럼 보여도 전체 건강이 정상이라고 판정하지 않는다. 연령, 임신, 개인 목표, 측정 장소는 확인되지 않았으므로 성인 참고 기준의 적용 한계를 명시한다.

- [질병관리청 고혈압 안내](https://health.kdca.go.kr/healthinfo/biz/health/gnrlzHealthInfo/gnrlzHealthInfo/gnrlzHealthInfoView.do?cntnts_sn=6765): 진료실 기준과 가정혈압 기준은 다르다. 가정혈압 135/85 기준은 반복 측정 평가의 참고 기준이며 단일값 진단에 사용하지 않는다. 염분 감소, 금연·절주 등의 생활 안내와 임의 약물 변경 금지를 포함한다. [가정혈압 기준 원문](https://health.kdca.go.kr/healthinfo/biz/health/ntcnInfo/healthSourc/thtimtCntnts/thtimtCntntsView.do?thtimt_cntnts_sn=28)을 함께 확인한다. 세부 개인 치료 목표를 구현하지 않았다.
- [AHA 가정혈압 안내](https://www.heart.org/en/health-topics/high-blood-pressure/understanding-blood-pressure-readings/monitoring-your-blood-pressure-at-home): 단일 높은 값은 재측정한다. 매우 높은 값과 흉통·숨참·신경학적 증상은 즉시 응급 연락 대상이며 증상 동반 시 재측정을 기다리도록 하지 않는다. AHA 원문은 180/120 초과라고 표기한다. 국내 안내의 180/120 이상 경계에 맞춰 경계값도 보수적 확인 대상으로 삼으며 이를 AHA의 정확한 경계라고 표현하지 않는다. 기록이 과거일 수 있으므로 현재 응급상태로 단정하지 않는다. 원본 값이 충돌해도 심한 값은 확인 안내에서 숨기지 않는다.
- [WHO 신체활동](https://www.who.int/news-room/fact-sheets/detail/physical-activity): 활동은 개인 능력과 상태에 맞춰 안내한다. 일부 걸음/운동 샘플로 하루 총량이나 운동 부족을 단정하지 않는다.
- [Apple HealthKit 권한](https://developer.apple.com/documentation/healthkit/authorizing-access-to-health-data): 앱은 읽기 권한 거부를 알 수 없고 접근 가능한 기간도 제한될 수 있다. 운동 기록 부재는 실제 운동을 안 했다는 증거가 아니다.

## 보존과 한계

기존 저장 보고서는 생성 당시 원문을 보존한다. 원시 기록 목록은 기본 접힘으로 두되 사용자가 펼치고 출처로 이동할 수 있다. 새 보고서의 표시용 수치/항목/시각만 지역화하며 모델에 전달하는 원본 값은 변경하지 않는다.

이번 단계는 혈압과 활동 안내, 기존 패턴 요약 및 표시 개선이다. 전체 건강의 임상적 진단, 모든 측정 항목의 정상/이상 판단, 과거 기준과 생활 맥락을 종합하는 모델 품질은 입증하지 않았다. 이 한계를 이유로 데이터 없는 항목을 정상 또는 운동 부족으로 채우지 않는다. 원본 저장·동의·긴급 안전 경계는 유지한다. 합성 테스트만 사용하며 실제 모델·실기기 검증을 주장하지 않는다.

## 개인 맥락 확인 질문

후속 보고서는 당일 snapshot에 있는 지속 중 증상, 혈압, 걸음/운동 기록에 맞춰 현재 증상과 측정 조건, 의료진이 정한 목표, 실제 활동과 운동 제한을 묻는다. 해소된 증상을 현재 증상으로 바꾸지 않으며, 운동 기록 부재를 운동하지 않았다는 답으로 채우지 않는다. 매우 높은 혈압 기록이 있으면 응급 안내가 대화 답변을 기다리는 절차로 보이지 않도록 추가 질문을 생략한다. 질문 자체는 새 외부 요청을 만들거나 건강정보를 새로 읽지 않는다.

이는 개인 맥락 수집을 위한 단계이며 답변을 이미 수집했다거나 개인별 종합 진단을 완료했다는 뜻이 아니다. 기존 보고서 재사용 시 과거 질문과 내용은 그대로 유지한다. 답변을 반영한 후속 수정은 기존 출처·동의·저장 경계로 처리해야 하며, 평소 기준이나 임상 목표를 임의 추정하지 않는다.

## 데이터 우선 보고서로 정정

사용자 정정에 따라 새 보고서는 자동 확인 질문을 만들지 않는다. 기존 저장 보고서는 수정하지 않으며, 이미 접근 가능한 원본을 먼저 종합한다. 복약은 명시적인 복용·누락·건너뜀·불명 상태를 구별하고, 당일 증상 및 저장된 진료 일정과 함께 실천 안내로 연결한다. 일정은 실제 참석이나 처방 변경의 증거가 아니다. 아직 시작하지 않은 당일 일정도 생성 시각 전에 저장된 **계획**으로만 포함하며, 미래 건강 측정은 계속 제외한다. 일정의 수정·삭제는 저장 검증과 기존 출처 추적에 반영한다.

전체 EventKit 일정은 아직 이 경로의 원본이 아니며 앱에 확정해 저장한 진료 일정만 포함한다. 개인정보나 캘린더 원본 제목을 새로운 외부 요청으로 전달하지 않는다. 모델에는 기존 동의한 사실 선택 요청만 유지한다. 복약 약명·개인 처방 목표·장기간 기준에 근거한 종합 임상 해석은 아직 완성되지 않았다. 이 부족한 범위를 질문으로 대신하거나 실제 진단을 완료했다고 주장하지 않는다.

[NHS Specialist Pharmacy Service 복용 누락 안내](https://sps.nhs.uk/articles/advising-on-missed-or-delayed-doses-of-medicines/)를 2026-11-15 확인했다. 약마다 조치가 다르므로 특정 복용 시각/용량을 임의 추천하지 않고 처방 지침·약사·의료진 확인을 안내한다. 누락과 증상의 인과관계나 약효를 단정하지 않는다.

## 연결된 약 정보

당일 복약 기록이 명시적으로 참조하는 약 등록/처방 원본만 같은 트랜잭션에서 읽는다. 지정된 source 범위를 넘지 않으며 생성 시각 이후, 삭제, stale, 크기 제한으로 제외된 정보는 약명 미확인으로 남긴다. 과거 약 정보의 시각은 오늘로 바꾸지 않고 `supportingRecordFor`로 당일 복약 기록과 구별한다. 연결된 원본은 동의할 정확한 요청·revision·출처 참조·삭제 검증에 포함한다. 이름이 확인된 복약 상태와 실천 안내를 함께 표시하지만, 등록·처방이 실제 복용이나 현재 사용을 증명하지는 않는다.

## 시스템 캘린더 계획의 별도 출처 경계

보고서 날짜의 반열린 구간으로 읽기 가능한 시스템 캘린더 전체를 조회한다. 보고서 생성은 권한 요청·일정 가져오기·원본 변경을 하지 않는다. 명시적인 로컬 sourceIds 범위가 있으면 캘린더를 덧붙이지 않는다. 읽기 실패·권한 부족은 범위 한계이며 일정이 없다는 근거가 아니다.

제목에서 명시적인 진료·건강 또는 운동 계획만 로컬에서 보수적으로 분류한다. 취소 일정은 계획에서 제외하며 미확정·상태 미상은 확정 참석으로 바꾸지 않는다. 모델에는 계획 종류·건수와 불확실성만 전달하고 원제목·캘린더 ID·위치·참석자는 보내거나 보고서에 저장하지 않는다. 실제 운동·진료 수행, 복용, 진단은 일정에서 추론하지 않는다. 원격 요청은 calendar_plans를 포함한 정확한 payload 동의를 새로 확인한다.

system_calendar 출처는 로컬 임상기록 lineage로 위장하지 않는다. 별도 날짜 범위와 revision binding을 context에 저장하고, 동의 이후 provider 실행 전·저장·재열기·파생 artifact 사용 시 native 조회로 검증한다. 저장 보고서의 원본 변화·권한철회·확인 불가가 관측되면 해당 보고서를 stale 처리하여 과거 내용을 다시 정상 결과로 노출하지 않는다. 캘린더 기반 인용은 이 검증을 받는 생성 보고서의 계획 요약으로 표시하며 독립적인 임상 원문으로 표시하지 않는다. EventKit과 SQLite의 원자적 트랜잭션을 보장하지는 않으며 저장 직후에도 살아 있는 snapshot의 변경 여부를 확인한다.

이는 당일 계획 맥락의 안전한 통합이지 장기 개인 기준선·약효·상호작용 또는 종합 건강 진단의 완성이 아니다. 합성 provider는 사실 선택·동의·출처 경계만 검증하며 실제 모델의 개인별 해석 품질을 입증하지 않는다.

## 개인별 최근 관측 맥락

최근 28개 현지 날짜의 호환 가능한 점 측정(안정시 심박수·체중·혈압)을 오늘과 함께 살핀다. 동일 지표·단위·출처만 묶고 출처 식별자가 없는 외부 측정, 서로 충돌하는 같은 시각의 측정, 걸음·수면 같은 누적량은 비교에서 제외한다. 관측된 날짜마다 중앙값을 구한 다음 그 일별 값의 중앙값을 오늘의 중앙값과 비교한다. 최소 3개 관측일은 화면에 비교를 표시하기 위한 기준일 뿐 임상적 표본 충분성이나 정상 범위를 뜻하지 않는다. 28일 전체가 측정되었다고 가정하지 않으며 개인 과거값도 고혈압 등 주의 수치 안내를 무효화하지 않는다.

과거 자료는 `personal_baseline` 역할과 실제 발생·수집 시각을 보존하고 당일 관측 및 개수와 분리한다. 동일 SQLite 스냅샷·출처 범위·수집 마감·용량 제한과 기존 변경/삭제 추적을 적용하며 외부 모델에는 기존 정확한 입력 동의를 받은 비교 문장만 포함한다. 최대 100개 과거 후보와 남은 입력 용량 안의 관측값만 사용하며 제한에 걸린 범위는 부분 조회로 표시한다. 운동/복약의 장기 추세와 의학적 종합 진단은 이 서술 비교만으로 완료되지 않는다.

## 기록된 복약·운동의 장기 맥락

오늘 복약 기록과 동일한 명시적 약 ID에 연결된 과거 28일 기록에서 완료·누락/건너뜀·미기록/불명을 분리한다. 완료 기록은 실제 복용·투여 완료로 표현한다. 전체 예정 회차나 누락된 날짜를 채우지 않으므로 복약 이행률을 계산하지 않는다. 과거 누락을 지금 보충하라는 지시나 용량 변경 없이 약별 지침 확인과 약사·의료진 상담으로 연결한다. [NHS SPS 원문](https://sps.nhs.uk/articles/advising-on-missed-or-delayed-doses-of-medicines/)을 2026-11-15에 확인했다.

운동은 양의 분 단위 값과 완료된 구간을 가진 운동 기록이 있는 날짜만 센다. 중복 기기 기록의 시간을 더하거나 기록 없는 날을 무활동으로 취급하지 않으며, 강도나 권장량 충족을 추정하지 않는다. [WHO 신체활동 안내](https://www.who.int/news-room/fact-sheets/detail/physical-activity)를 2026-11-15에 확인해 몸 상태·운동 제한을 전제로 가능한 활동부터 이어가도록 안내한다. 당일 매우 높은 혈압 기록이 있으면 운동 격려 대신 기존 응급·재확인 안내를 우선한다.

과거 맥락은 원래 자료와 별도의 역할을 유지하고 당일 사실이나 개수로 합치지 않는다. 동일 입력 스냅샷과 출처 범위, 수집 마감, 남은 용량을 지키며 종류별 최대 50개 후보 제한은 부분 조회로 표시한다. 기존 정확한 외부 전송 동의와 삭제·수정 무효화 경로를 그대로 적용한다. 진단·약효·인과관계는 이 기록 패턴만으로 판단하지 않는다.

## 주제별 보고서 구성

새 보고서는 검토된 안전·생활 안내를 먼저, 복약·진료 행동 안내, 관측된 과거 기록 비교, 오늘의 기록 흐름, 목적이 미확정인 캘린더 제목 일치 계획, 판단 한계 순으로 구성한다. 분류는 저장 시 부여하는 선택적 표시 메타데이터이며 임상 판단이나 정상 판정이 아니다. 어떤 근거 문장도 요약을 이유로 삭제하지 않고 출처 연결을 유지한다. 이전 보고서는 재분류하거나 문구를 변경하지 않는다. 새 기준·약물 용량·모델 자유 생성 진단을 추가하지 않는다.

## 근거 인용형 모델 해석

단순 사실 인덱스 선택만 요청하던 호출을, 선택한 기록의 관계와 한계를 한국어로 설명하는 제한된 해석으로 확장한다. 동일한 한 번의 호출에 날짜·시간대·조회 마감·자료 범위, 식별자 제거된 사실과 검토된 안내를 포함하고 새 정책 버전의 정확한 전송 내용 동의를 받는다. 원문 기록은 명령이 아닌 불신 데이터로 취급한다.

해석은 최대 네 항목, 각 800자이며 유효한 사실 인덱스를 인용해야 하며 자유 해석은 적어도 하나의 실제 evidence 역할 자료를 포함해야 한다. 숫자가 인용문에 없는 경우와 명백한 진단·약 변경 등 일부 위험 문구는 거절한다. 이 검사들은 의미적 정확성·의학적 안전성·인과관계의 타당성을 증명하지 않는다. 실천 안내는 모델이 새로 쓰지 않고 이미 검토된 안내 중 선택한 문장을 그대로 표시한다. 개인별 정상 판정·새 진단·약 용량 변경·임의 임계값은 허용하지 않는다.

유효한 사실 선택이 있는 경우 해석 부분의 구조·인용 검증 실패는 생성 문장만 폐기하고 기존 보고서를 유지한다. 당일 매우 높은 혈압의 기존 확인 경계에서는 해석 부분이 잘못된 형태여도 먼저 폐기하여 모델 해석을 표시하지 않고 검토된 긴급 안내를 유지한다. 일반 경우도 기존 안전 안내가 생성 해석보다 앞에 남는다. 생성된 문장에는 저장·재열기·근거 열람 후에도 AI 해석이라는 표지가 남으며 원래 출처와 삭제·권한·시점 검사를 공유한다. 이전 인덱스 전용 응답은 기존 결정적 보고서로만 처리하며 생성 해석으로 주장하지 않는다.

합성 제공자와 자료로 출력 계약·정확 동의·취소·저장·출처 삭제를 검증한다. 실제 모델의 임상적 해석 품질과 프롬프트 주입 저항은 이 합성 검증으로 확인되지 않았으며 별도 승인된 품질 평가 없이는 검증 완료라고 표현하지 않는다. AHA 가정혈압 원문(2026-11-15 조회)은 단일 측정만으로 진단하지 않으며 증상 동반 매우 높은 혈압에서 대기하지 않는 경계를 재확인하는 데 사용했다. 새 임상 기준을 추가한 것은 아니다.

## 고빈도 측정과 범위 내 페이지 조회

선택한 날짜와 출처 범위의 기록은 같은 데이터베이스 transaction에서 100행씩 읽는다. 이 크기는 조회 배치이며 종류별 100개나 공용 64 KiB에서 전체 읽기를 중단하지 않는다. 정상 레코드도 16 KiB라는 이유만으로 제외하지 않는다. 건강 자료와 증상·복약·일정 및 연결 약 정보는 원래 시각과 출처를 유지한다.

권한 범위 밖의 자료, 조회 마감 이후 자료와 오래된 출처는 그대로 제외한다. 실제 미지원 자료나 조회 공백은 범위 표시에 남기며 모든 과거 질병이나 현재 상태를 확인했다는 뜻으로 해석하지 않는다. 취소·schema·삭제와 revision 검증을 그대로 적용한다.

## 이전에 시작된 증상 맥락

보고서는 명시적으로 `active`로 저장되고 해결 시각이 없는 증상을 시작일이
오늘 이전이어도 읽습니다. 원래 시작 시각, 상태, 출처 및 revision은 유지하며,
`ongoing_symptom`은 오늘 새로 관측한 증상이 아니라 이전 기록의 지속 상태입니다.
현재 실제 상태를 새로 확인한 것으로 표현하지 않습니다. 오래된 기록의 상태가
없다는 이유만으로 지속 중 예외를 허용하지 않습니다.

해소된 증상은 실제 `resolvedAt` 구간이 보고서 날짜와 겹칠 때만 포함합니다.
오늘 이전이나 자정에 이미 해소된 기록은 현재 증상으로 가져오지 않으며,
생성 시각 이후의 해결 정보도 미리 사용하지 않습니다. 선택한 날짜·출처 범위와 실제 부분 조회 표시는 유지되므로 모든 과거 증상이나 만성 질환을 확인했다는
의미가 아닙니다. 외부 모델 전송은 정확한 payload 동의를 그대로 거치고,
원본 삭제나 변경 시 저장 보고서의 기존 lineage 검증을 따릅니다.

합성 SQLite 회귀는 오래된 active, 이전 해소, 오늘 해소, 자정 경계,
미래 해결·늦은 ingestion 제외, source scope, 원시 시각과 동의 payload,
저장 후 원본 삭제에 따른 보고서 숨김을 검증합니다. 실제 개인 자료나
외부 모델 품질을 검증한 결과는 아닙니다.

## 과거 자료의 관련성 선별과 예산 분리

과거 기준선 후보는 오늘 비교 가능한 지표·단위·출처와 일치하는 자료를
기존 행 제한 전에 좁힙니다. JSON 속성 순서가 달라도 현재 출처 스키마의
각 필드를 비교하며, 디코딩 후 기존 전체 출처 동일성 검사는 유지합니다.
지표·출처별로 최근 후보를 순환 선택하므로 다른 지표의 고빈도 표본이
한도를 먼저 차지하는 일을 줄입니다. 과거 복약은 오늘 기록의 명시적인
definition/assertion 연결 ID가 일치하는 후보만 제한 전에 읽습니다.
약 이름이 같다는 이유로 연결하거나 실제 복용 상태를 변경하지 않습니다.

남은 과거 입력 용량의 최대 절반을 기준선에 배정하고 나머지 및 미사용
기준선 공간을 복약·운동에 남깁니다. 복약도 자기 예산의 최대 절반까지만
사용해 운동 기록의 공간을 확보합니다. 이는 제한된 자료의 다양성을 위한
예산이며 전체 28일의 완전성이나 통계적 대표성을 보장하지 않습니다.
기존 부분 조회·누락 설명, 원시 시각, 승인된 source 범위, 생성 마감,
stale 제외, 정확한 요청 동의 및 원본 변경·삭제 추적을 그대로 유지합니다.

합성 SQLite 회귀는 관련 없는 심박·다른 출처 체중·다른 약 각각 120개와
작은 공용 과거 예산에서도 관련 체중·실제 복약·운동이 함께 남는지 확인합니다.
실제 개인 자료와 외부 모델 품질 검증은 수행하지 않습니다.

## 수면 구간의 해석 가능한 맥락

수면 stage 원시 코드 대신 이미 승인된 스냅샷의 수면 구간을 보고서 날짜의
실제 시작·마감 시각 안으로 자릅니다. 일광절약시간 전환을 고정 24시간으로
가정하지 않습니다. 동일 출처의 asleep 단계는 구간 합집합으로 중복을 제거하며
inBed와 awake를 더하지 않습니다. 서로 다른 출처 시간도 합산하지 않습니다.
같은 출처에서 깨어 있음과 수면이 겹치면 어느 쪽을 임의로 선택하지 않고
수면시간 계산을 숨깁니다. 알 수 없는 단계나 부적절한 구간은 미확인으로 남깁니다.

[Apple 수면 단계 공식 문서](https://developer.apple.com/documentation/healthkit/hkcategoryvaluesleepanalysis)
(2026-11-15 조회)는 in-bed와 단계 구간의 중첩, 그리고 실제 상세 기록이
밤의 시작·끝을 모두 포함하지 않을 수 있음을 설명합니다. 따라서 표시값은
부분 관측 구간일 뿐 완전한 밤의 수면량·수면의 질·충분성·질환 진단이 아닙니다.
최대 세 출처 그룹의 요약과 생략 한계를 표시하며 식별이 불분명한 외부
출처는 서로 합치지 않습니다. 수면 구간 부재는 잠을 자지 않았다는 뜻이 아닙니다.

요약은 원본 인용을 유지한 사실로 기존 모델 입력의 정확한 동의를 거치며,
저장 보고서에도 같은 문장을 보존합니다. 원본 삭제 시 기존 보고서 삭제
추적을 따릅니다. 합성 구간과 SQLite 검증은 중복·자정·DST·상충 단계·
미확인 단계·동의·저장·삭제 경계를 검사하며 실제 모델 품질을 검증하지 않습니다.

## 상충하는 혈압 기록의 확인 행동

2026-11-16 [AHA 가정혈압 원문](https://www.heart.org/en/health-topics/high-blood-pressure/understanding-blood-pressure-readings/monitoring-your-blood-pressure-at-home)과 [심장마비 경고 증상 원문](https://www.heart.org/en/health-topics/heart-attack/warning-signs-of-a-heart-attack)을 재확인했다. 휴식, 적절한 커프·팔 위치, 1분 간격의 두 측정 및 각각의 기록, 의료진과 기기 확인은 가정 측정 안내에 근거한다. 현재 경고 증상에서 기다리지 않는 안내는 별도의 응급 증상 원문에 근거하며 낮은 혈압이 안전을 증명한다는 뜻이 아니다.

같은 시각·같은 항목·같은 단위의 다른 값이라는 판정은 앱의 기존 자료 품질 규칙이지 AHA가 정의한 진단 기준이 아니다. 서로 다른 기기에서도 생길 수 있고 어느 기록이 정확한지 또는 고장·질환인지 판단하지 않는다. 두 원본을 인용해 확인 방법을 안내하되 평균을 만들거나 낮은 값을 채택하지 않는다. 기존 매우 높은 혈압 경계가 하나라도 있으면 기존 응급 안내가 우선하며 새 확인 문구로 대체하지 않는다. 다른 시각, 다른 단위 또는 동일값 중복은 이 확인 안내의 새로운 근거가 아니다.

안내는 기존 정확한 전송 내용 동의와 저장·출처 삭제 경로에 들어가며 과거 보고서를 다시 쓰지 않는다. 합성 경계 테스트는 출력 계약만 검증하고 실제 모델의 임상적 품질이나 사용자의 전체 건강 해석 완료를 입증하지 않는다.

## 진료 일정에 종속되지 않는 증상 후속 행동

2026-11-17 [NHS Trust의 긴급·응급 진료 안내](https://www.croydonhealthservices.nhs.uk/for-urgent-and-emergency-care-2/)와
[NHS 진료 준비 안내](https://www.nhs.uk/nhs-services/gps/what-to-ask-your-doctor/)를 확인했다.
지속되거나 악화되는 증상은 의료진 상담으로 연결하고, 상담 준비에는 시작 시점과
악화·완화 상황을 기록한다. 응급 상황은 기록 정리나 예약을 기다리는 절차가 아니다.
영국 서비스 번호를 한국 사용자에게 옮기거나 개별 증상의 진단·치료 지침을 추가하지 않는다.

승인된 스냅샷에 active 상태의 증상이 있지만 취소되지 않은 진료 일정이 없을 때도
출처가 연결된 후속 행동을 제공한다. 일정의 부재가 실제 예약 부재를 증명하지는 않는다.
과거 active 상태는 현재의 임상 판단이 아니므로 현재 증상은 조건부로 표현한다.
resolved 상태는 이 안내의 근거로 사용하지 않는다. 일정이 있으면 기존 준비 안내를
유지하고 중복하지 않는다. 높은 혈압의 우선 안내·복약과 운동 안내·정확한 요청 동의·
기존 출처 변경 및 삭제 추적은 그대로다. 기존 저장 문장을 다시 쓰지 않는다.
합성 테스트는 이 출력 경계만 입증하며 실제 모델의 전체 해석 품질을 입증하지 않는다.
