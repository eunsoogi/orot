# 대화 선택지의 답변 서식

네 선택지는 대화 안에서 결과를 보여 주지만, 생성과 검증 경로는 서로 다릅니다.

| 선택지             | 생성 경로                              | 표시와 복원                                                                          |
| ------------------ | -------------------------------------- | ------------------------------------------------------------------------------------ |
| 질병 가능성 보고서 | 가능성 안전 지침이 적용된 grounded RAG | 명시적인 보고서 제목과 다섯 섹션이 모두 있는 최종 답변만 섹션으로 표시합니다.        |
| 진료 질문          | 별도의 진료 질문 준비 워크플로         | 기존 질문 검토·선택·수정 카드와 저장 질문 복원을 유지합니다.                         |
| 내 건강 정보 요약  | 건강 요약 서비스                       | 검증된 요약 섹션, 기간, 출처, 저장 상태를 기존 카드에 표시합니다.                    |
| 오늘의 보고서      | 일일 보고서 서비스                     | 저장된 보고서의 섹션 순서와 본문을 명시적인 제목으로 직렬화하고 대화에서 표시합니다. |

`ConversationReportSection`은 제목과 본문 간격만 공유합니다. 출처 권한, 저장 상태,
질문 선택 상태를 갖지 않으며 별도의 스크롤이나 글자 수 제한을 추가하지 않습니다.
가능성 보고서의 제목·섹션은 형식이며, 진단이나 근거 검증 결과를 뜻하지 않습니다.

가능성 선택지를 누른 최초 요청에만 출력 형식을 안내합니다. 자유로운 후속 질문에는
그 안내를 추가하지 않습니다. 모델의 형식 준수는 실제 모델 검증과 별개입니다.
서식이 다르거나 섹션이 누락된 답변을 재생성하거나 내용에서 임의로 추론하지 않고
원문 그대로 보여 줍니다. 사용자 메시지와 진행 중·중단된 출력도 보고서로 승격하지
않습니다. 기존의 구조 없는 저장 답변에는 없는 섹션을 만들어 넣지 않습니다.

새 표시를 위한 데이터 사본이나 저장 필드는 없습니다. 보관된 답변 문자열을 그대로
읽으며, 기존 출처 검증과 삭제·세션 소유권 경계를 통과한 메시지에만 적용됩니다.
임상 검증, 인용, 동의, 모델 이력의 신뢰 구분은 바꾸지 않습니다. 모델 입력 지침의
변경은 task v14에 속하며, 허용된 과거 task 복원에서는 새 서식 지침을 제외합니다.

합성 컴포넌트와 저장·복원 테스트는 이 구조를 검증합니다. 실제 모델의 서식 준수,
의학적 품질, 실기기에서의 가독성과 지연 개선을 입증하지는 않습니다.
