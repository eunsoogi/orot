# 이슈 #204 화면 목업

이 폴더에는 이슈 #204의 최종 화면 구현 기준을 담은 생성 이미지가 있습니다.

- [`records-tab.png`](records-tab.png): 녹음, 저장된 녹음, 가져온 건강 기록으로 이동하는 기록 탭.
- [`settings-integrations.png`](settings-integrations.png): 자동 건강 데이터 동기화, 권한 및 동기화 복구 설정.
- [`recording-session.png`](recording-session.png): 녹음 중 상태. 마이크 탭으로 녹음을 마치고, 일시 정지는 아이콘으로 조작합니다. 내부 녹음 ID는 표시하지 않습니다.
- [`transcript-review.png`](transcript-review.png): 녹음 흐름 안의 전사 검토 및 편집 섹션.
- [`recording-export.png`](recording-export.png): 같은 녹음 흐름 안의 내보내기 섹션. 전사 검토와 별도 경로가 아닙니다.
- [`imported-health-records.png`](imported-health-records.png): 혈압 시계열을 차트로 먼저 보여 주는 건강 기록 화면.
- [`imported-health-records-detail.png`](imported-health-records-detail.png): 차트의 상세 동작으로 여는 별도 원자료 목록. 날짜, 시간과 수축기·이완기 값은 차트와 일치합니다.
- [`schedule.png`](schedule.png): 가져오기 버튼이나 동기화 완료 표시는 없으며, AI 일정 분류는 사용자가 직접 실행합니다. 캘린더 동기화는 화면에 표시하지 않고 백그라운드에서 동작합니다.

건강 기록의 모든 수치와 일정은 `예시 목업`입니다. 사용자 실제 건강 정보나 일정으로 취급하지 마세요. 루트 화면은 기존 하단 탭을, 상세 화면은 기존 하단 뒤로·홈 조작을 유지합니다. 이 이미지들은 요청된 본문 화면의 기준이며 새 내비게이션 설계가 아닙니다.
