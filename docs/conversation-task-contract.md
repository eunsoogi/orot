# 기록과 대화 작업 계약

기록과 대화의 작업은 대화 세션에 속합니다. 홈, 알림 또는 링크가 작업을 선택하는 것만으로 초안을 채우거나 전송하지 않으며, AI 실행과 기록 전송은 별도 사용자 요청과 필요한 동의 뒤에만 시작합니다. 시스템의 날짜 선택기와 권한 요청은 그대로 사용합니다.

공유 카드 상태는 `ConversationTaskCard`와 `RetainedConversationTask`에 정의합니다. 카드에는 작업 종류와 확인에 필요한 식별자만 저장합니다. 안전 입력, 기록 원문, 생성된 본문, 동의 응답과 임시 진행 상태를 카드에 복사하지 않습니다. 저장된 치료 설명과 보고서의 본문 및 출처는 기존 저장소와 검증 경로가 소유합니다.

- 일일 보고서 카드는 날짜와 시간대의 정규화된 식별자를 보관합니다. 저장된 결과에 연결할 때는 실행 ID와 결과 버전도 함께 보관합니다. 결과를 표시하거나 후속 대화에 사용할 때 현재 저장 결과와 출처를 다시 확인합니다. 다른 버전이 같은 날짜에 생겼다고 이전 결과를 새 버전으로 대체하지 않습니다.
- 치료 설명 카드는 같은 대화에 저장된 결과의 식별자와 결과 버전을 보관합니다. 결과를 열 때는 저장된 버전, 현재 세션과 출처를 다시 확인하고 안전 입력과 필요한 확인을 거칩니다. 원본이나 결과가 삭제되면 이를 참조하는 카드는 함께 제거되거나 내용을 표시하지 않습니다.

카드 저장은 암호화된 대화 저장소를 사용합니다. 세션 버전은 삭제와 복구 전후의 쓰기를 구분하고, 카드 버전은 같은 카드의 동시 수정이 서로 덮어쓰지 않게 합니다. 실행 중 상태는 재시작 후 실행 중인 것처럼 복원하지 않습니다. 결과 저장과 치료 카드 생성은 같은 트랜잭션에서 처리합니다.

후속 화면이나 진입 경로는 카드와 결과를 복제하는 별도 저장소를 만들지 않습니다. 작업 선택, 결과 확인, 출처 열기, 생성과 재시도는 각각 명시적인 동작입니다. 이 계약은 실제 기기에서의 복원이나 외부 모델의 성공적인 실행을 증명하지 않습니다.
